// FEATURES

Toolbox for the Paranoid

Everything you need to secure, encode, and hash — all running locally in your browser. Nothing ever leaves your machine.

[B64]

Base64 Encode/Decode

Convert any text or binary data to and from Base64 encoding instantly. Perfect for API payloads and data URIs.

[AES]

AES-256 Encryption

Military-grade symmetric encryption with your own passphrase. CBC mode with PBKDF2 key derivation.

[PWD]

Password Strength Checker

Real-time analysis of password entropy, common patterns, dictionary matches, and brute-force time estimates.

[FIL]

File Encryptor

Drag-and-drop file encryption using AES-256. Your files never leave the browser — processed entirely client-side.

[#!]

Hash Generator

Generate MD5, SHA-1, SHA-256, and SHA-512 hashes instantly. Verify file integrity and compare checksums.

[0x0]

Zero Server Processing

No data is ever transmitted. Every operation runs 100% in your browser using the Web Crypto API and local JS.
